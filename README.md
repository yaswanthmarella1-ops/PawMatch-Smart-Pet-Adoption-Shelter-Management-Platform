# PawMatch-Smart-Pet-Adoption-Shelter-Management-Platform
PawMatch is a serverless Pet Adoption CRM built with HTML, JS, Bootstrap, Dexie.js, and Chart.js. By bringing IndexedDB relational databases directly to the browser, it delivers an offline-first experience. Featuring medical timelines, analytics, and a polished SaaS UI, it streamlines workflows to match pets with forever homes.
